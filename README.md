# Healing Horizon — Fast, polished React MVP

## Included
- Sticky glass-style navigation
- Original hero image optimized to WebP
- Services
- About / story
- Trust strip
- Stats
- 4-step care journey
- Team profiles
- Testimonials placeholder
- Appointment / registration form
- Wellness resource cards
- FAQ accordion
- Contact section
- Responsive mobile layout
- No external images, icon libraries, analytics or font requests

## Run
npm install
npm run dev

## Production
npm run build
npm run preview

## Performance
The hero image is local and compressed WebP. Below-the-fold image usage is lazy-loaded.
The site does not depend on Google Fonts or external image hosts, so it remains fast and stable even when third-party resources are unavailable.

## Before launch
Replace placeholder team/testimonial details, add the final privacy/consent language, connect the forms to a free form/scheduling provider, and add the actual Healing Horizon contact details.
